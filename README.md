# 하키티비 스코어보드 (HockeyTV Scoreboard)

keepthescore 대체용으로 만든 **아이스하키 전용 OBS 스코어보드**입니다.
파일은 `index.html` **하나뿐**이고, 서버 프로그램이나 설치가 필요 없습니다.

---

## 1. 먼저 5초 테스트 (인터넷 올리기 전)

`index.html`을 더블클릭하면 조작 화면이 바로 열립니다.
점수 +1, 시계 시작, 페널티 추가를 눌러보고 위쪽 미리보기가 잘 바뀌는지 확인하세요.

> 💡 이 상태로도 OBS에 연결됩니다. 다만 주소가 길고 지저분해서, 아래처럼 GitHub에 올려두는 걸 권합니다.

---

## 2. GitHub Pages에 올리기 (무료 · 10분)

1. <https://github.com> 로그인 → 우측 상단 **＋ → New repository**
2. Repository name에 `scoreboard` 입력 → **Public** 선택 → **Create repository**
3. 만들어진 화면에서 **Add file → Upload files**
4. `index.html`을 드래그해서 올리고 아래 **Commit changes** 클릭
5. 위쪽 탭 **Settings → 왼쪽 메뉴 Pages**
6. **Source: Deploy from a branch**, **Branch: main / (root)** 선택 → **Save**
7. 1~2분 뒤 아래 주소로 접속됩니다

```
https://내깃허브아이디.github.io/scoreboard/
```

이 주소가 앞으로 **조작 화면**입니다. 즐겨찾기 해두세요.

> 나중에 디자인을 바꾸고 싶으면 새 `index.html`을 같은 방법으로 다시 업로드하면 끝입니다.

---

## 3. OBS에 연결하기

1. 조작 화면 맨 위 **📋 OBS 스코어버그 주소 복사** 클릭
2. OBS → 소스 **＋** → **브라우저**
3. **URL**에 붙여넣기
4. **너비 1400 / 높이 320** 정도로 설정 (나중에 크기 조절 가능)
5. 아래 두 개는 **체크 해제**해 주세요
   - ☐ 보이지 않을 때 소스 종료
   - ☐ 장면이 활성화될 때 브라우저 새로 고침
6. 골혼·부저 소리를 방송에 내보내려면 **☑ OBS를 통해 오디오 제어** 체크

> 배경은 이미 투명하게 나오므로 사용자 정의 CSS는 건드릴 필요 없습니다.

**하단 티커**를 따로 쓰고 싶으면 `📋 OBS 티커 주소 복사`로 소스를 하나 더 만드세요.

## 4. 여러 명이 동시에 쓰기 (팀 모드)

하키티비 직원 여러 명이 **각자 다른 경기장에서 동시에** 중계할 수 있습니다. 보드는 서로 완전히 분리됩니다.

### 처음 열면 나오는 설정 창

| 항목 | 설명 |
|---|---|
| **팀 공용 키** | 하키티비 팀원 **전원이 같은 값**을 씁니다. 처음 쓰는 사람이 만든 값을 팀에 공유하고, 나머지는 그대로 붙여넣으세요. 외부에 공개하지 마세요 |
| **내 보드 이름** | 사람마다 **다르게** 정합니다. 영문·숫자로 짧게 (`rink1`, `kim`, `u18` 등) |
| **담당자 이름** | 선택. 팀 현황판에 표시됩니다 |

이 두 값으로 내 전용 주소가 자동으로 만들어집니다:

```
팀키 = htv-ab12cd34,  보드 = rink1
→ https://.../scoreboard/?view=bug&room=htv-ab12cd34_rink1
```

보드 이름만 다르면 **점수·시계·페널티·기록이 서로 전혀 섞이지 않습니다.**

### 우리 팀 현황 (실시간)

조작 화면 중간에 **지금 켜져 있는 팀원들의 보드가 실시간으로 표시**됩니다.

- 보드 이름 · 담당자 · 대진 · 현재 스코어 · 피리어드
- 초록 점 = 시계가 돌아가는 중 / 회색 점 = 정지
- 누가 지금 중계 중인지 한눈에 보이고, 사무실에서 전체 경기 상황을 파악할 수 있습니다

### ⚠ 보드 이름이 겹치면

같은 팀 키에서 두 사람이 같은 보드 이름을 쓰면 **빨간 경고가 뜹니다.** 그대로 두면 서로 점수를 덮어쓰니 즉시 설정에서 이름을 바꾸세요.

### 설정을 팀 전체에 맞추기

한 사람이 글꼴·색상·피리어드·티커 스타일을 잡아두고 → **⬆ 현재 설정을 팀에 배포**
나머지 팀원은 → **⬇ 팀 설정 가져오기** 한 번이면 똑같은 모양이 됩니다.

> 배포되는 건 **모양 설정만**입니다. 점수·시계·경기 기록은 각자 따로 유지됩니다.

### 연결 상태

우측 상단 표시가 **🟢** 이면 정상, **🟠** 면 인터넷 연결을 확인하고 새로고침하세요.

## 6. 기능 요약

- 점수 · SOG(유효슛) · 전적/순위 표시
- **다중 페널티 타이머** — 선수 번호 + 시간, 게임시계와 함께 카운트다운, 0이 되면 자동 제거
- 파워플레이 표시 모드
- 엠티넷 / 타임아웃 배너
- **피리어드 자유 설정** — 개수·이름·길이 모두 편집 (대회마다 다른 규칙 대응)
- 게임시계 (내려감/올라감), 0초 자동 부저, 수동 부저
- **골 애니메이션 + 골혼** (내장 사운드 또는 내 mp3 업로드)
- **승부치기(슛아웃) 모드** — 라운드 자동 계산, 팀별 성공/실패 점 표시, 되돌리기
- 팀 로고 업로드, 팀 색상, **자주 쓰는 팀 저장/불러오기**
- **리플레이 표시** — 다시보기를 틀 때 빨간 "리플레이" 배지를 띄우고 점수판을 흐리게
- **경기 기록 자동 저장** — 골·페널티·타임아웃·피리어드·슛아웃이 자동으로 쌓이고 CSV/요약/JSON으로 내보내기
- 하단 스크롤 티커
- 레이아웃 3종: 스코어버그(가로) / 중앙정렬 / 전체화면 스코어보드
- **글꼴 분리 선택** — 영문/숫자용 글꼴(Bebas Neue, Oswald, Anton 등)과 한글용 글꼴을 따로 지정
  - 기본값: **검은고딕 Black Han Sans** — 영문·숫자까지 같은 글꼴로 통일
  - 그 밖에: 본고딕 · 코트라 볼드체 · 코트라 도약체 · 코트라 희망체 · 여기어때 잘난체 · 고딕 A1 · 도현 · 주아 · 나눔고딕 · 송명
  - **두 목록 모두에 전체 글꼴이 들어 있습니다** — 위 칸은 영문·숫자, 아래 칸은 한글에 적용
  - 위 칸에서 "↑ 한글 글꼴과 동일하게"를 고르면 전체가 한 글꼴로 통일됩니다
  - **글자 굵기**: 보통(기본) / 중간 / 굵게 / 아주 굵게 (코트라·잘난체·검은고딕처럼 굵기가 하나뿐인 글꼴은 변화 없음)
  - 원하는 글꼴이 없으면 [눈누](https://noonnu.cc)에서 웹폰트 주소(woff/woff2)만 복사해 **직접 추가**할 수 있습니다
- 한국어 ↔ English 전환
- 설정 내보내기/불러오기 (JSON)

## 7. 문제가 생기면

| 증상 | 해결 |
|---|---|
| OBS에 아무것도 안 보임 | 주소 끝의 `?view=bug&room=...` 부분이 그대로 복사됐는지 확인 |
| OBS 화면이 안 바뀜 | 조작 화면 우측 상단이 🟢인지 확인 → 🟠이면 인터넷 연결 확인 후 새로고침 |
| 글꼴이 OBS 텍스트 소스와 달라 보임 | 같은 글꼴이라도 **굵기**가 다르면 인상이 완전히 달라집니다. 설정 → 보드 외형 → **글자 굵기**를 맞춰보세요 (OBS의 Regular = 보통) |
| 글꼴이 안 바뀜 | 인터넷 연결 필요 (구글 폰트 사용). OBS 소스를 한 번 새로고침 |
| 소리가 안 남 | OBS 브라우저 소스 속성에서 "OBS를 통해 오디오 제어" 체크 |
| 크기가 작음/큼 | 설정 → 보드 외형 → 글자 크기 `+ / −` |

## 9. 라이브 중 즉석 리플레이 (10초 전으로 되감기)

되감기 자체는 **OBS의 "다시보기 버퍼"** 기능으로 합니다. 스코어보드는 리플레이가 나가는 동안 화면에 "리플레이" 표시를 띄우는 역할을 합니다.

### 9-1. OBS 다시보기 버퍼 켜기

1. OBS → **설정 → 출력** → 위쪽 출력 방식을 **고급**으로
2. **다시보기 버퍼** 탭 → ☑ **다시보기 버퍼 활성화**
3. **최대 재생 시간**: `20`초 (10초 리플레이를 원해도 여유 있게 20초 권장)
4. **최대 메모리**: `512` MB 정도
5. 설정 → **단축키** → "다시보기 버퍼 저장"에 원하는 키 지정 (예: `F9`)
6. OBS 메인 화면 오른쪽 아래 **"다시보기 버퍼 시작"** 클릭 — 방송 시작할 때마다 눌러야 합니다

이제 좋은 장면이 나온 직후 `F9`를 누르면 **직전 20초가 파일로 저장**됩니다.

### 9-2. 저장한 장면을 화면에 바로 틀기

OBS에 기본 포함된 스크립트를 쓰면 저장과 동시에 자동 재생됩니다.

1. 장면에 **미디어 소스**를 하나 추가 (이름: `Replay`, 로컬 파일은 비워둠, ☑ 재생 완료 시 소스 숨기기)
2. OBS → **도구 → 스크립트** → **＋** → `instant-replay.lua` 선택 (OBS 기본 제공)
3. 스크립트 설정에서 **미디어 소스**를 방금 만든 `Replay`로 지정
4. 이제 `F9`를 누르면 → 직전 장면이 저장되고 → `Replay` 소스가 자동 재생됩니다

> 10초만 보여주고 싶으면 최대 재생 시간을 `10`으로 두면 됩니다.
> 더 정교하게(속도 조절, 여러 각도) 쓰려면 **Aitum / Advanced Replay Buffer** 같은 플러그인을 추가로 쓰기도 합니다.

### 9-3. 스코어보드와 함께 쓰기

`F9`를 누른 직후 스코어보드 조작 화면에서 **`R` 키** 또는 **🔴 리플레이 표시** 버튼을 누르세요.

- 스코어버그 위에 빨간 **리플레이** 배지가 깜빡입니다
- 점수판은 흐려져서 "지금은 실시간이 아님"이 한눈에 보입니다 (설정 → 보드 외형에서 끌 수 있음)
- 리플레이가 끝나면 `R`을 한 번 더 눌러 끄면 됩니다

> ⚠️ 리플레이 중에도 게임시계는 계속 돌아갑니다. 실제 경기는 멈춰 있으니, 리플레이는 **경기가 끊긴 사이**(득점 직후, 페널티 후)에 트는 것이 안전합니다.

## 10. 경기 기록 자동 저장

조작 화면 아래 **경기 기록** 칸에 경기 중 일어난 일이 자동으로 쌓입니다. 따로 누를 것은 없습니다.

### 자동으로 기록되는 것

| 종류 | 기록되는 내용 |
|---|---|
| 골 / 골 취소 | 시계 시각, 피리어드, 팀, 그 시점 스코어 |
| 페널티 | 선수 번호, 부여 시간 |
| 페널티 종료 | 시간이 다 되어 자동으로 풀린 시각 |
| 타임아웃 · 엠티넷 | 팀, 시각 |
| 피리어드 변경 | 몇 피리어드로 넘어갔는지 |
| 슛아웃 성공/실패 | 팀, 라운드 |
| 경기 종료 | 최종 스코어 |
| 메모 | 직접 입력한 내용 |

시계 시작·정지까지 남기고 싶으면 기록 칸 오른쪽 **"시계 시작·정지도 기록"** 을 켜세요. (기본 꺼짐 — 켜면 줄 수가 많이 늘어납니다)

**메모**는 자동으로 잡히지 않는 것(골리 교체, 비디오 판독, 부상 등)을 적어두는 칸입니다. 입력하고 `Enter`만 치면 그 시점 시계와 함께 저장됩니다.

기록은 브라우저에 저장되므로 실수로 새로고침해도 사라지지 않습니다. 각 줄 오른쪽 `✕`로 잘못 들어간 줄만 지울 수도 있습니다.

### 내보내기 3종

- **⬇ CSV (엑셀)** — 엑셀·구글 시트에서 바로 열리는 표. 한글 안 깨집니다. 기록 정리·통계용
- **⬇ 경기 요약 (txt)** — 사람이 읽는 요약본. 최종 스코어, 유효슛, 득점 목록, 페널티 목록, 슛아웃 결과, 메모가 정리돼 있어서 **유튜브 영상 설명란이나 경기 리포트에 그대로 붙여넣기** 좋습니다
- **⬇ JSON** — 나중에 다른 프로그램에서 불러 쓸 때

파일 이름은 `20260727_루비덕스_vs_블루이글스.csv` 형태로 자동 생성됩니다.

### 다음 경기 시작할 때

맨 위 **↺ 경기 초기화**를 누르면 "이전 경기 기록도 지울까요?"를 한 번 더 물어봅니다.

- **확인** → 기록까지 깨끗하게 비우고 새 경기 시작
- **취소** → 점수·시계만 초기화하고 기록은 이어서 남김 (하루에 여러 경기를 한 파일로 남기고 싶을 때)

> 💡 경기 끝나면 **내보내기를 먼저** 하세요. 초기화하고 기록을 지우면 되돌릴 수 없습니다.
