1 사이트 접속

중계에 쓸 PC의 크롬(Chrome)으로 아래 주소에 접속합니다. 즐겨찾기에 등록해 두세요.

https://hockeytv.github.io/scoreboard/

설치할 프로그램은 없습니다. 이 주소로 접속한 화면이 점수를 조작하는 화면입니다.

이 매뉴얼은 조작 화면 맨 위 📖 사용 매뉴얼 버튼으로 언제든 다시 열 수 있습니다.

💡 두 개의 화면이 있습니다 조작 화면은 내가 보면서 버튼을 누르는 곳이고, 스코어버그는 시청자에게 보이는 그래픽입니다. 조작 화면에서 누르면 스코어버그가 실시간으로 바뀝니다.

2 처음 한 번만 — 내 보드 만들기

처음 접속하면 설정 창이 뜹니다. 이 설정은 한 번만 하면 됩니다.

팀 공용 키하키티비 전 직원이 똑같은 값을 씁니다. 관리자에게 받아서 그대로 붙여넣으세요. 자동으로 채워진 값이 있어도 반드시 받은 값으로 바꿔야 합니다.
내 보드 이름사람마다 다르게 정합니다. 영문·숫자로 짧게. 예: rink1, kim, u18
담당자 이름선택 사항. 팀 현황판에 표시됩니다.

시작하기를 누르면 내 전용 주소가 자동으로 만들어집니다. 보드 이름만 다르면 다른 직원과 점수가 절대 섞이지 않습니다.

⚠ 보드 이름이 겹치면 화면 중간 우리 팀 현황에 빨간 경고가 뜹니다. 그대로 두면 두 사람의 점수가 서로 덮어써지니, 즉시 설정에서 다른 이름으로 바꾸세요.

나중에 바꾸려면 설정 → 사운드·티커·OBS 주소 칸에서 수정할 수 있습니다. (바꾸면 OBS 주소도 다시 넣어야 합니다)

3 OBS에 연결하기

  1. 조작 화면 맨 위의 📋 OBS 스코어버그 주소 복사를 클릭합니다.
  2. OBS에서 소스 ＋ → 브라우저를 선택하고 이름을 정합니다.
  3. URL 칸에 복사한 주소를 붙여넣습니다.
  4. 너비 1920 / 높이 1080 으로 입력합니다. 이 값이 가장 중요합니다.
  5. 아래 두 항목은 체크를 해제합니다.
    • ☐ 보이지 않을 때 소스 종료
    • ☐ 장면이 활성화될 때 브라우저 새로 고침
  6. 골혼·부저 소리를 방송에 내보내려면 ☑ OBS를 통해 오디오 제어를 체크합니다.
  7. 확인을 누르고, 소스를 우클릭 → 변환 → 변환 초기화를 한 번 해줍니다.
⚠ OBS에서 마우스로 끌어서 크기를 조절하지 마세요 스코어보드는 1920×1080 화면 전체를 기준으로 위치가 계산됩니다. 소스를 1920×1080으로 두면 저절로 딱 맞습니다. 끌어서 늘리면 화질만 흐려집니다.
위치·크기는 조작 화면에서 바꾸세요 → 설정 → 보드 레이아웃(화면 위치·여백), 보드 외형(글자 크기).

배경은 이미 투명하게 나오므로 사용자 정의 CSS는 건드릴 필요가 없습니다. 하단 스크롤 자막을 따로 쓰려면 📋 OBS 티커 주소 복사로 브라우저 소스를 하나 더 만드세요.

💡 미리보기의 파란 테두리 = 실제 방송 화면 조작 화면 위쪽 미리보기에서 파란 테두리 안쪽이 1920×1080 화면이고, 체크무늬는 투명(뒤 영상이 비치는) 영역입니다. 테두리 바깥의 어두운 부분은 화면 밖이라 방송에 나가지 않습니다. 미리보기에서 보이는 그대로 OBS에도 나옵니다.

4 경기 시작 전 준비

조작 화면 아래 설정 영역에서 준비합니다. 위쪽 미리보기가 실제 방송 화면과 똑같이 보이니, 미리보기를 보면서 맞추면 됩니다.

팀 정보

  • 팀 이름 / 전적 입력 (전적은 비워도 됩니다)
  • 배경색 · 글자색 — 팀 유니폼 색에 맞추면 보기 좋습니다
  • 팀 로고 — 이미지 파일 선택. 크기는 − +로 조절
  • 자주 쓰는 팀은 현재 팀 저장 해두면 다음 경기에 저장된 팀 불러오기로 한 번에 불러옵니다
  • 홈·어웨이가 반대면 홈/어웨이 바꾸기 한 번

경기 규칙

  • 타이머 설정 → 피리어드 구성에서 이름과 길이를 대회에 맞게 수정합니다 (예: 15분 3피리어드)
  • 피리어드를 추가·삭제할 수 있습니다

화면 꾸미기

  • 보드 외형 → 제목 표시를 켜고 대회명을 입력하면 스코어보드 위에 표시됩니다
  • 글자 크기 + − 로 스코어보드 전체 크기 조절
  • 화면 위치: 좌측 상단 / 중앙 상단 / 우측 상단 / 좌측 하단 / 중앙 하단 / 우측 하단 (기본: 좌측 상단)
  • 화면 가장자리 여백: 기본 40px
  • 글꼴: 영문·숫자용과 한글용을 따로 고를 수 있습니다 (기본: 검은고딕)

방송 화면 글자도 한글로 바꾸려면 설정 → 보드 외형 → 보드에 나오는 글자 언어를 한국어로 바꾸세요.

5-1 OBS 옆에 두고 쓰기 (창 배치)

보통 왼쪽에 조작 화면, 오른쪽에 OBS를 놓고 씁니다. 조작 화면은 창 너비에 맞춰 자동으로 정리됩니다.

창 너비보이는 칸
약 650px 이상4칸 전부 — 홈 · 어웨이 · 타이머 · 경기 상태
500 ~ 650px3칸 (경기 상태는 아래로)
500px 미만2칸
💡 라이브 중에는 미리보기를 끄세요 실제 화면은 OBS에서 보고 계시니, 미리보기 오른쪽 숨기기를 누르면 조작 버튼이 훨씬 많이 보입니다. 숨긴 상태는 기억되어 다음에 열 때도 그대로 시작합니다. 다시 보려면 같은 자리의 보기를 누르세요.

창을 좁히면 버튼과 글자가 자동으로 작아져서 스크롤 없이 조작할 수 있습니다. 넓히면 원래 크기로 돌아옵니다.

6 페널티 넣고 빼기

추가

  1. 해당 팀의 페널티 추가를 누릅니다. (팝업창은 뜨지 않습니다)
  2. 선수 번호를 입력합니다. (몰라도 비워두고 진행 가능)
  3. 2:00 / 4:00 / 5:00 / 10:00 중 하나를 클릭합니다.
    다른 시간은 아래 칸에 1:30 처럼 입력하고 추가를 누르세요.

수정 · 해제

추가된 줄에 버튼이 있습니다.

+1 / -11초씩 조정
+30 / -3030초씩 조정
✕즉시 해제 (상대 팀이 득점했을 때 등)
  • 페널티는 게임시계가 돌 때만 줄어듭니다. 시계를 멈추면 같이 멈춥니다.
  • 시간이 0이 되면 자동으로 사라집니다.
  • 한 팀에 여러 개를 동시에 걸 수 있습니다.

개별 페널티 대신 "파워플레이 2:00" 형태로 보이게 하려면 설정 → 보드 외형 → 개별 페널티 대신 '파워플레이' 표시를 켜세요.

7 승부치기(슛아웃)

  1. 경기 상태 칸의 승부치기(슛아웃) 모드를 켭니다. 피리어드가 자동으로 SO로 바뀝니다.
  2. 선수가 슛을 쏠 때마다 해당 팀의 ✔ 성공 또는 ✖ 실패를 누릅니다.
  3. 화면에는 성공 🟢, 실패 🔴, 아직 안 쏨 ⚪ 으로 표시되고 라운드는 자동 계산됩니다.
  4. 잘못 눌렀으면 ↩ 되돌리기, 처음부터 다시 하려면 슛아웃 초기화.
  5. 승부치기가 끝나면 승리 팀 점수를 +1 해주세요.
✔ 슛아웃 모드를 끄면 직전 피리어드와 시계가 자동으로 되돌아옵니다. 따로 초기화할 필요 없습니다.

8 경기가 끝나면

⚠ 순서를 꼭 지키세요 — 내보내기 먼저, 초기화는 나중에 초기화하면서 기록을 지우면 되돌릴 수 없습니다.

골·페널티·타임아웃·피리어드·슛아웃이 자동으로 기록되어 있습니다. 경기 기록 칸에서 내보내세요.

⬇ 경기 요약 (txt)최종 스코어·득점·페널티가 정리된 요약본. 유튜브 설명란에 그대로 붙여넣기 좋습니다
⬇ CSV (엑셀)엑셀·구글 시트에서 바로 열립니다. 기록 정리·통계용
⬇ JSON다른 프로그램에서 불러 쓸 때

내보낸 뒤 맨 위 ↺ 경기 초기화를 누르면 점수·시계·페널티가 초기화됩니다. "이전 경기 기록도 지울까요?"를 한 번 더 묻습니다.

  • 확인 → 기록까지 비우고 새 경기 시작
  • 취소 → 점수만 초기화하고 기록은 이어서 남김 (하루에 여러 경기를 한 파일로 남길 때)

9 문제가 생겼을 때

OBS에 아무것도 안 보임주소 끝에 ?view=bug&room=... 부분까지 다 붙여넣었는지 확인. 소스 크기가 1920×1080인지 확인
OBS 화면이 안 바뀜조작 화면 오른쪽 위가 🟢인지 확인. 🟠면 인터넷 연결 확인 후 새로고침. OBS 소스는 속성 창의 새로고침 버튼
스코어보드가 잘림OBS 소스 크기를 1920×1080으로. 그 뒤 소스 우클릭 → 변환 → 변환 초기화
내가 누른 게 다른 사람 화면에 나옴보드 이름이 겹친 것입니다. 설정에서 다른 이름으로 변경
소리가 안 남OBS 브라우저 소스 속성에서 OBS를 통해 오디오 제어 체크
글꼴이 이상함인터넷 연결 필요(웹폰트 사용). 새로고침 Ctrl+Shift+R (맥: Cmd+Shift+R)
화면이 예전 버전 같음강력 새로고침 Ctrl/Cmd+Shift+R
버튼 칸이 2개만 보임창이 좁아서 그렇습니다. 창을 조금 넓히면 4칸이 됩니다. 미리보기 숨기기도 도움이 됩니다
미리보기에서 스코어보드가 가운데 떠 있는 것 같음정상입니다. 파란 테두리 안쪽이 실제 화면이고, 스코어보드는 그 좌측 상단에 붙어 있습니다
페널티 시간이 안 맞음페널티는 게임시계가 돌 때만 줄어듭니다. 시계가 멈춰 있지 않은지 확인하세요

10 꼭 지켜야 할 것

1. 팀 공용 키는 외부에 공개하지 마세요 이 키를 아는 사람은 우리 스코어보드를 볼 수 있습니다. 카톡 단톡방·유튜브 댓글·화면 공유 등에 노출되지 않게 주의하세요.
2. 보드 이름은 사람마다 다르게 같은 이름을 쓰면 두 사람의 점수가 서로 덮어써집니다. 빨간 경고가 뜨면 즉시 바꾸세요.
3. 경기 기록은 내보낸 뒤에 초기화 기록은 이 PC의 브라우저에만 저장됩니다. 지우면 복구할 수 없습니다.
4. 방송 전 5분 점검
  • 조작 화면 오른쪽 위 🟢 확인
  • OBS 브라우저 소스 1920×1080 확인
